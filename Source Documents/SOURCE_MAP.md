\# Source Map



This folder contains multiple generations of design material for the Bounded Predictive Machine project.



\## Design Generations



\### Prototype 1 / Original Design



Folder:



`V0 - V9/`



Status:



Historical/original design generation.



Use:



\- Treat as the earliest structured safety/runtime design.

\- Use for design lineage, original runtime concepts, and earlier versioned structure.

\- Do not treat as automatically current if it conflicts with later material.



\### Prototype 2 Design



Folder:



`1-17/`



Status:



Second prototype design generation.



Use:



\- Treat as a later technical prototype that expands the cognitive architecture.

\- Use for cognitive-core concepts, cognitive tick, data model, developmental ladder, and original-alignment evaluation.

\- Do not treat as automatically current if it conflicts with Prototype 3 material.



\### Prototype 3 / Current Design



Folder:



Root files directly inside `Source Documents/`, not including files inside `V0 - V9/` or `1-17/`.



Status:



Current design direction.



Use:



\- Treat as the most current source of truth.

\- Use as the primary basis for new technical documentation.

\- Use Prototype 1 and Prototype 2 as historical context, design lineage, and supporting detail.



\## Conflict Rule



If documents conflict:



1\. Prefer Prototype 3 / current design.

2\. Use Prototype 2 as supporting context if compatible.

3\. Use Prototype 1 as historical/original context if compatible.

4\. If a conflict is important, document it instead of silently merging the ideas.



\## Documentation Rule



Technical documentation should clearly distinguish:



\- current architecture

\- inherited concepts

\- historical design lineage

\- superseded or unresolved ideas



Do not flatten all source material into one undifferentiated canon.
